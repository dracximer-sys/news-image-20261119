One image summing up the world's news of Thursday, 19 November 2026 — a newspaper front page with 45 stories, 3 original illustrations and a world map with numbered pins. Lead stories: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, the ICJ ruling that Myanmar committed genocide against the Rohingya, and Anthropic's record $81.3bn IPO debut on Nasdaq. Also inside: the day in numbers, a big world map of where it happened, the rest of the day in a numbered list, and an explicit DATE CHECK box listing the stories that were deliberately left out because they happened on another day. All artwork is original drawings.

## Run it

```sh
python3 main.py
```

Writes the image to `entry.png` (1024×1024 PNG, deterministic, no network — the illustrations and map are read from `illustrations/` and `map.jpg`).
